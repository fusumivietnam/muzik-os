# M+ review prototype (not production)

React source with no separate dependency manifest or framework. After the official starter is integrated, mount the default export from MPlus.jsx in a local-only React entry point using the existing runtime; do not register a public application route. CSS is scoped to the prototype. No deployment, real music data, external imagery, audio or external listening endpoints.

Review at 1440, 390 and 320 CSS pixels, light/dark, Home/Search/Artist/Release/Recording, keyboard navigation, long labels and empty search. All data and artwork are fictional. Proposed CSS variables are review candidates only. Do not copy to production tokens or record a Playwright baseline until approval. Runtime and browser testing pending.
